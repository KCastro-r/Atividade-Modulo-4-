# 🧩 Lista de Exercícios - Fundamentos de Programação com C#

## 📌 Sobre o projeto

Este repositório contém uma lista de exercícios desenvolvidos em **C#**, com o objetivo de praticar os fundamentos da programação, incluindo:

- Entrada e saída de dados;
- Variáveis e tipos de dados;
- Operadores matemáticos;
- Estruturas condicionais (`if/else`);
- Estruturas de repetição (`for`, `while`);
- Vetores (arrays);
- Manipulação de dados;
- Geração de números aleatórios.

## 🚀 Tecnologias utilizadas

- C#
- .NET
- Visual Studio / Visual Studio Code

---

# 📚 Lista de Exercícios

## 1. Soma de dois números

Solicite dois números inteiros e exiba a soma.

### Exemplo

**Entrada:**
```
10
15
```

**Saída:**
```
A soma é 25.
```

---

## 2. Antecessor e sucessor

Leia um número inteiro e mostre:

- Antecessor;
- Número informado;
- Sucessor.

---

## 3. Área de um retângulo

Solicite:

- Base;
- Altura.

Calcule:

- Área;
- Perímetro.

---

## 4. Conversor de moedas

Leia um valor em reais e a cotação do dólar.

Mostre quanto esse valor representa em dólares.

---

## 5. Calculadora simples

Solicite dois números e mostre:

- Soma;
- Subtração;
- Multiplicação;
- Divisão.

---

## 6. Contagem crescente

Exiba os números de **1 até 100**.

---

## 7. Contagem regressiva

Exiba os números de **50 até 1**.

---

## 8. Tabuada

Solicite um número e exiba sua tabuada de **1 a 10**.

---

## 9. Soma dos números pares

Calcule a soma de todos os números pares entre **1 e 100**.

---

## 10. Login simples

Solicite usuário e senha.

Enquanto a senha estiver incorreta, solicite novamente até que o acesso seja permitido.

---

## 11. Soma até digitar zero

Leia números inteiros.

Quando o usuário digitar **zero**, encerre o programa mostrando a soma dos valores informados.

---

## 12. Contador de caracteres

Leia um nome e informe a quantidade de caracteres.

---

## 13. Verificador de senha

Solicite uma senha.

Informe se ela possui pelo menos **8 caracteres**.

---

## 14. Maior elemento

Leia **10 números** e informe:

- Maior valor;
- Posição em que ele aparece.

---

## 15. Média de um vetor

Leia **8 notas** e calcule a média.

---

## 16. Contagem de pares

Leia **20 números** e informe quantos são pares.

---

## 17. Ordem inversa

Leia **10 números** e exiba-os na ordem inversa.

---

## 18. Jogo da senha

Gere um número aleatório entre **1 e 100**.

O usuário deverá tentar acertar o número.

O programa deve informar se o número digitado é:

- Maior que o número sorteado;
- Menor que o número sorteado;

Até que o usuário acerte.

---

## 19. Caixa eletrônico

Solicite um valor para saque.

Informe a quantidade de notas entregues considerando:

- 💵 R$100
- 💵 R$50
- 💵 R$20
- 💵 R$10
- 💵 R$5
- 💵 R$2
